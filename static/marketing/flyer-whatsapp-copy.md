## Notas de uso

- Enviar el PNG primero, después el copy en el mismo chat (WhatsApp muestra primero la imagen y debajo el texto formateado).
- Para envíos masivos usar **listas de difusión** o la API de WhatsApp Business: enviar uno por uno a contactos no agendados puede ser percibido como spam.
- Personalizar el saludo con el nombre del destinatario cuando sea posible (`Hola, Dr. Pérez 👋`).
- En grupos profesionales o colegios, preferir la **versión corta** y un mensaje previo de presentación.
